# Panattoni-ügy Herceghalmon

Lakossági tájékoztató weboldal a herceghalmi (440/5 hrsz.) Panattoni logisztikai beruházásról: aktuális fejlemények, 2021–2027-es idővonal, a kért szabálymódosítás, a „mit ad – mit kap” mérleg, a telekcsere, a környezeti hatás, egy rövid kisfilm és a 2026. november 2-i lakossági fórum.

Ez lakossági kezdeményezés, nem Herceghalom Község Önkormányzatának és nem a beruházónak az oldala. Az adatok nyilvános iratokból származnak; a források az oldal alján szerepelnek.

## Közzététel

A teljes oldal egyetlen fájl (`index.html`) és egy kép. GitHub Pages-en: Settings → Pages → Source: „Deploy from a branch”, Branch: `main`, mappa: `/ (root)`.
