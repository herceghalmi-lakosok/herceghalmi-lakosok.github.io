# Panattoni-ügy Herceghalmon

Lakossági tájékoztató weboldal a herceghalmi (440/5 hrsz.) Panattoni logisztikai beruházásról: aktuális fejlemények, 2021–2027-es idővonal, a kért szabálymódosítás, a „mit ad – mit kap” mérleg, a telekcsere, a környezeti hatás, két kisfilm (köztük az „Az ördöglovas vázlatfüzete” narrált videó) és a 2026. november 2-i lakossági fórum (KEK, Gesztenyés út 36.).

Ez lakossági kezdeményezés, nem Herceghalom Község Önkormányzatának és nem a beruházónak az oldala. Az adatok nyilvános iratokból származnak; a források az oldal alján szerepelnek.

## Közzététel

A teljes oldal egyetlen fájl (`index.html`), két kép és egy videó (`ordoglovas-vazlatfuzet.mp4`, `ordoglovas-poster.jpg`). GitHub Pages-en: Settings → Pages → Source: „Deploy from a branch”, Branch: `main`, mappa: `/ (root)`.
